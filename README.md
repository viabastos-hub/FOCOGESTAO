# 🧼💰 FOCO GESTÃO - Aplicativo de Higienização & Cálculo de Lucro

**FOCO GESTÃO** é um aplicativo mobile progressivo (PWA) de altíssima simplicidade visual, projetado especialmente para profissionais e autônomos do ramo de higienização de estofados, colchões, artigos infantis e estética automotiva.

---

## 🎯 Principais Diferenciais para o seu Cliente Leigo

- **🔐 Login Permanente por CPF/CNPJ (Sem Senhas Difíceis)**: A pessoa digita o CPF ou CNPJ 1 única vez no celular e o app mantém a sessão ativa para sempre. **Nunca perde os dados e não precisa ficar logando toda hora.**
- **📊 Termômetro de Lucratividade em Tempo Real**:
  - 🔴 **Pouco Lucro (Margem Baixa)**: Avisa se a margem for arriscada e sugere reajuste.
  - 🟡 **Lucro Médio (Margem Padrão)**: Confirma que o valor cobre os custos com segurança.
  - 🟢 **Lucro Excelente (Alta Margem)**: Mostra que o valor multiplica o faturamento diário.
- **🧪 Cálculo Automático por ML**: Basta digitar quanto usou do produto (ex: 150ml) e o app calcula os centavos exatos consumidos.
- **📋 Gerador de Orçamento no WhatsApp com Foto & Tecido**: Formata a mensagem com valores, tecido, fotos do estofado e envia direto para o WhatsApp do cliente.
- **📅 Agenda Integrada**: Mostra os serviços do dia, abre a rota do endereço no GPS/Waze e permite atualizar o status de cada atendimento.
- **💡 Dicas de Precificação & Marketing**: Aba dedicada com guias de precificação, como anunciar no Google Meu Negócio e scripts prontos de venda para copiar e colar no WhatsApp.

## 🚀 Como Subir o Projeto para o GitHub

Se você já tem o Git instalado no seu computador, siga os passos no terminal dentro desta pasta:

```bash
# 1. Inicializar o repositório Git
git init

# 2. Adicionar todos os arquivos
git add .

# 3. Criar o primeiro commit
git commit -m "Versão Atualizada VPB HigiLucro PWA"

# 4. Conectar ao seu repositório do GitHub (Substitua a URL pelo seu link do GitHub)
git remote add origin https://github.com/SEU-USUARIO/vpb-higilucro.git

# 5. Enviar para a branch principal
git branch -M main
git push -u origin main
```

## 🌐 Hospedagem Gratuita em 1 Clique (Vercel ou Netlify)

Para disponibilizar o link do aplicativo para os seus compradores da Kiwify:

1. Acesse [vercel.com](https://vercel.com) ou [netlify.com](https://netlify.com).
2. Conecte sua conta do GitHub.
3. Importe o repositório `vpb-higilucro`.
4. Clique em **Deploy**.
5. Pronto! Em 5 segundos você terá um link profissional HTTPS (ex: `https://vpb-higilucro.vercel.app`) para entregar na Kiwify!

---

## 💳 Como Entregar na Kiwify

1. **Link Direto (Recomendado)**: Na Kiwify, configure a entrega do produto como "Acesso a um Link" e cole o link do seu app (ex: Vercel/Netlify). O cliente clica no link pelo celular, informa seu CPF/CNPJ no primeiro acesso e já começa a usar imediatamente.
2. **Arquivo ZIP**: Zipar todo o conteúdo desta pasta `vpb-higilucro` e disponibilizar para download.

## 📲 Como o Cliente Instala no Celular (Adicionar à Tela Inicial)

Instruções simples para incluir no seu material de vendas:

### No Android (Google Chrome)
1. Abra o link do aplicativo no Chrome.
2. Toque nos **3 pontinhos** no canto superior direito.
3. Toque em **"Adicionar à tela inicial"** ou **"Instalar aplicativo"**.

### No iPhone / iPad (Safari)
1. Abra o link do aplicativo no Safari.
2. Toque no botão de **Compartilhar** (quadrado com seta para cima no rodapé).
3. Role para baixo e toque em **"Adicionar à Tela de Início"**.
